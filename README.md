### 1. Чем C# отличается от Python с точки зрения ошибок?

C# сначала компилируется, поэтому многие ошибки программа находит ещё до запуска. В Python некоторые ошибки появляются уже во время выполнения программы.

### 2. Что делает `dotnet run`?

Эта команда сначала собирает программу, а потом запускает её. То есть сначала идёт компиляция, затем запуск.

### 3. Зачем нужны `bin/` и `obj/`?

В этих папках находятся файлы, которые создаются автоматически при сборке проекта. В Git их обычно не добавляют, потому что они могут создаваться заново.

### 4. Чем `git commit` отличается от `git push`?

`git commit` сохраняет изменения у меня на компьютере. `git push` отправляет эти изменения на GitHub.

### 5. Чем отличаются `+` и интерполяция?

С помощью `+` строки соединяются вручную:

```csharp
"Привет, " + name
```

А при интерполяции можно сразу вставлять переменные:

```csharp
$"Привет, {name}"
```

Интерполяция обычно удобнее и код с ней выглядит понятнее.

### 6. Что будет при делении `int` на `int`?

Дробная часть просто потеряется. Например:

```csharp
5 / 2
```

получится `2`, а не `2.5`.

Чтобы получить дробный результат, нужно использовать `double`:

```csharp
5.0 / 2
```

### 7. Чем `const` отличается от обычной переменной?

`const` нельзя изменить после создания. Например:

```csharp
const double Pi = 3.14;
```

Так можно хранить значение, которое всегда должно оставаться одинаковым.

### 8. Что такое top-level statements?

Это возможность писать код C# прямо в `Program.cs`, не создавая вручную `class Program` и `static void Main()`. Для небольших программ это просто и удобно.
